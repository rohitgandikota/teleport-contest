# Reviewed selection contract

Complete C weapon.c705-742 and JS weapon.js960-999 select_hwep prefer eligible artifacts first. C then tests is_giant, followed by Balrog identity and the hero's actual uwep. C decl.h94-96 declares uwep separately from uswapwep. JS setuwep354-380 and setworn128-215 update game.u.uwep through W_WEP, not game.uwep. A carried or alternate-only sword therefore must not enable the Balrog preference.

Complete oselect (C476-497, JS920-938), can_touch_safely (Cmon1958-1974, JSmon2197-2216), and artifact contact (Cartifact908-976, JSartifact1078-1160) preserve safe inventory-order selection. Nonartifact contact returns without random draws. Complete mon_wield_item (C801-933, JS1045-1175) selects before changing the monster's weapon, clears old wield state, emits the wield message, then sets W_WEP and returns a consumed move. No helper or message changes are required for the two ordinary weapons.

Complete m_initweap (Cmakemon161-571, JS1799-2134) gives Balrogs a bullwhip then a broadsword, and continues through generic demon equipment generation. Complete mongets (C2181-2232, JS736-785) uses mksobj and mpickobj and forbids blessed demon objects. The observed source setup independently requires both ordinary weapons and rejects any artifact. The selected makemon finish contexts (C1441-1455, JS2510-2522) run weapon initialization before extra inventory and armor. The selected dochug contexts (Cmonmove840-859, JS1445-1462) set NEED_HTH_WEAPON and await wielding before movement. Adjacent-attack fallback contexts (Cmhitu883-901, JS1199-1216) likewise choose before attack. These are caller contexts, not a claim of complete dochug/mattacku or all creation-owner parity.

The direct JS select_hwep caller census is weapon.mon_wield_item and minion's guardian-Angel equipment path. mon_wield_item also has callers in dog, vault, mthrowu, monmove, mhitu and mhitm. Only the real hostile Balrog route is demonstrated by these inputs. There are no new exports, helper substitutions, injected state or mocked RNG.

C is_giant tests M2_GIANT; the existing JS S_GIANT class check is separately discrepant and remains byte-identical. Artifacts, shields, petrifying corpses, silver contact, unarmed monster species and other callers remain unobserved here. The early artifact branch and normal hwep order are preserved.
