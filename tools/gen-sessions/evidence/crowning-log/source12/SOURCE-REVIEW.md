# Crowning event audit

Complete C gcrownu, pray.c:805-998, and fixed JS gcrownu were read. C logs all three alignment titles, the class spellbook, lawful transformation, neutral artifact gift and chaotic artifact gift. JS omits all seven log sites. This packet tests the maintained lawful Excalibur, neutral Wizard book and chaotic Stormbringer producers, followed by a real chronicle command. It does not claim coverage for Monk, held artifacts, pre-existing artifacts, alternate pronouns, or a giftless crowning.

C gamelog_add/livelog_printf, pline.c:494-526, records category, current turn and copied text. C do_gamelog/show_gamelog, insight.c:2532-2598, includes spoiler entries in wizard mode. This family uses that existing mode. Final-event filtering and ordinary-mode spoiler filtering are separate from these missing emitters.

Constants global.h and JS const.js give LL_DIVINEGIFT=8, LL_ARTIFACT=64, LL_SPOILER=8192. Complete actualoname and JS counterpart override identification around minimal naming. C captures this book name before blessing/dropping. C captures simpleonames before the lawful transformation and uses the hero gender from flags.female. The maintained lawful hero is female. The three deity names are verified in role.c and role_data.js: Tyr, Thoth, Kos. C u_gname and the JS align_gname select the current alignment deity. No naming helper changes are proposed.

Inputs, prediction body and source hashes are fixed before the first new JS replay, C recording or runtime edit. The passive observer copies only state. Observed, plain and deferred runs must match all five output streams. Three uncrowned controls must retain their full hashes. The initial failure and any setup failure will be preserved.
