# Vault restoration pet feedback

C calls yelp for a tame boundary occupant before relocating it. The port now
awaits that existing helper in wallify_vault. An awake dog eating a real corpse
reaches the missing call. A silent tame monster and an empty boundary retain
their complete output. All three keyboard cases match the original C recording.

Run `node tools/wallify-vault-occupant-input-gate.mjs` for fresh ordinary checks.
The gate verifies the unchanged C recording and input metadata before importing
the game. Its default invocation writes no files.

SOURCE-REVIEW.md is the original source-only audit, preserved verbatim. Its
pending-native statements describe that earlier stage. The recording receipt,
native validation and the [combined checkpoint](../vault-flags-feedback/README.md)
record the subsequent comparisons. The original failed proposals remain in the
sealed source packet identified by source-seal.json.

These cases do not cover sleeping pets, deafness, hallucination, nearby sleeping
monsters, running cancellation or relocation failure. Debris disposal, trap
cleanup and wall-state calculation remain separate wallify gaps.
